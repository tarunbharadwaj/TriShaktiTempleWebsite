# Sri Sri Sri Trishakti Devalayam

A bilingual, responsive React website for the temple's 2026 Dussehra celebrations.

## Run locally

```powershell
npm install
npm run dev
```

## Production checks

```powershell
npm run lint
npm run build
npm run preview
```

All editable temple content is centralized in `src/data/content.js`. The four poster assets live in `public/posters/` and can be replaced independently without changing the rest of the site.
